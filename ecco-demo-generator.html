Deploy steps
  1. Copy the BRAND config above.
  2. Open your local copy of ecco-app.html.
  3. Find the existing const BRAND = { block near the top of the <script> section.
  4. Replace it with the generated config. Save as index.html.
  5. Create a new GitHub repo named ecco-demo-mars-men and upload the file.
  6. Import the repo into Vercel as a new project.
  7. Add the custom domain mars-men.demo.eccoapp.ai in Vercel's domains settings, then add the CNAME record in Cloudflare.
  8. Send the URL to the prospect 48 hours before the meeting.
